What you can do

From raw PDFs to a chat app with verifiable, downloadable sources — all through the web UI.

📚

Build knowledge bases

Split → Docling Markdown → JSON chunking → metadata + L1/L2/L3 keyword dictionary → Qdrant ingest.

🧩

Rule Builder

Generate a domain system-prompt from sample documents — compare A/B/C, then pick or synthesize.

✅

Verification & QC

Coverage check (source ↔ vector DB) and a dual-AI answer audit before you go live.

💬

Cloud chat apps

Wire an Open WebUI app to an n8n query webhook in two clicks — no URLs to copy.

🔗

Citations + downloads

Every answer lists the source files it used, each downloadable for verification.

🌐

Bilingual UI

Toggle EN / 中文 anytime — including content returned from the backend.

Quick Start

Hand it to your AI coding agent — no manual setup. Open Claude Code / Antigravity / Codex and give it two URLs; it installs and wires everything end-to-end.

1
Give your agent two URLs
① the OpenGenie AI Stack (infrastructure)  ② this repo (the application)
2
It deploys OpenGenie first
n8n · Qdrant · Open WebUI · Docling · PostgreSQL · Redis · FileBrowser
3
Then it installs this app & connects them
compose up → import n8n workflows → install Open WebUI pipes — following AGENTS.md / INSTALL.md
4
You provide one secret
a Cloud AI API key (any OpenAI-compatible endpoint). That's the only manual step.

繁體中文

開源、網頁式的 RAG 知識庫建置平台,同時是 OpenGenie AI Stack 的官方範例應用 —— 示範如何把這套自架 AI 基礎設施變成可用的產品。上傳 PDF → 切檔 → Docling 轉檔 → 切塊 + 關鍵字 → 灌入 Qdrant → 透過 Open WebUI 問答,每個答案都附可下載的原始檔出處。全程網頁、中英雙語、免寫程式。

安裝(免動手):打開 AI coding agent(Claude Code / Antigravity / Codex),把兩個 URL 丟給它 —— ① OpenGenie AI Stack(基礎設施)② 本 repo(應用),agent 會自己裝完串接,只跟你要一把 Cloud AI API key。映像檔為 multi-arch(amd64 + arm64,含 NVIDIA Grace/GB10)。地端 AI、Rerank 重排、多模態型錄 RAG、跨文件知識圖譜(跨報告多跳交叉查詢)屬付費版。
